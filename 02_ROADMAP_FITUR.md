# 🗺️ Roadmap & Tahapan Pengembangan Fitur

## 📌 Fase 1: MVP (Minimum Viable Product) - Wajib Ada
* [ ] Antarmuka dasar (HTML/CSS) responsif (HP & Laptop).
* [ ] Fungsi utama tools bisa berjalan dan memberikan hasil yang benar.
* [ ] Pengujian dasar di browser lokal.

---

## 🚀 Fase 2: Peningkatan Interaksi & Kerapian (Enhancement)
* [ ] Animasi transisi yang halus dan indikator loading.
* [ ] Penyimpanan data lokal (*Local Storage* di browser) agar input tidak hilang saat di-refresh.
* [ ] Tombol *Salin Hasil* (*Copy to Clipboard*) atau *Unduh File*.

---

## 🔮 Fase 3: Fitur Masa Depan (Advanced)
* [ ] Integrasi backend / database jika diperlukan.
* [ ] Akun pengguna / otentikasi login.
* [ ] Siap dipublikasikan ke internet (Hosting / Domain publik).
